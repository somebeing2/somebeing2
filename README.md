### SQL Studio · Natural-Language-to-SQL Proof of Concept
**Federal Bank · Planning MIS Department · Python · SQL · RAG**

Designed and built with the Planning MIS team during my Applied AI internship at Federal Bank. This was a proof of concept, not a production system.

- Developed a retrieval-augmented natural-language-to-SQL workflow across 168 validated Finacle tables from a schema of more than 900 tables.
- Combined query decomposition, domain and temporal routing, BM25 and vector retrieval, Reciprocal Rank Fusion, cross-encoder reranking, graph-based join planning and SQL validation.
- Improved execution accuracy from 25.9% to 83.0% on a 1,000-query benchmark through data-engineering and schema-context improvements.
- Built a reusable knowledge base containing table descriptions, join relationships, decode mappings and query-pattern templates.
- Estimated a potential annual saving of 4,070+ hours; this was a projection, not a realised saving.
